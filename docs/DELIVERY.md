### 音声タイミング調整の書き出し（再検証済み・第57ラウンド追補）
- 正のずらしは音声入力に +itsoffset（edit list 付き）、負のずらしは音声の内容自体を |Δ| だけ進めて切り出す（映像＝基準トラックを動かさない。動かすと再生時に正規化されて消える）。いずれもパケットコピーで無変換。
- 負のずらしが区間全体を素材終端より後ろに押し出す場合は映像のみで書き出し警告を付与（空カットの ffmpeg 失敗を回避）。
- 字幕は常に映像入力に同梱（無変換・非 mute 時）。`shifted` 判定に連動させていたため素の無変換と負のずらしで字幕が脱落する回帰があったため修正。E2E で 0/±2000ms の字幕存続と [2s,6s) 由来を検証。
- E2E tests/e2e_audio_export.py は全合格（内容レベル同期オラクル＋独立パケット格子＋字幕回帰を含む）。

### 無変換カット方式（重要）
- この ffmpeg ビルドでは Matroska で入力シーク（-ss を -i の前）が無効、出力シークは「ss より後のキーフレーム」を選ぶ。
- そのため映像は「直前キーフレームと開始キーフレームの中間」から出力シークして開始キーフレームに着地させ、音声・字幕は開始時刻ちょうどから別途切り出し、両者を -itsoffset で 0 起点に揃えて mux する 3 パス方式にした。映像・音声の A/V 同期と尺を両立する。
- 先行キーフレームが無い場合（IN が先頭キーフレーム以前）は、先頭キーフレームの DTS が B フレーム遅延で負になり得るため、1 秒手前の負の位置から出力シークして先頭キーフレームを保持する。

## 既知の制限
- 無変換カットの終端は exact（指定時刻）のため、末尾 1〜2 フレームが境界で一致しない場合がある（内容は破損せず、デコードエラーもない）。
- 無変換カットは 3 パス（映像切り出し・音声切り出し・mux）のため、単一パスより I/O が多い。
- 書き出しの一時ファイルは出力先フォルダに作るため、プロセス強制終了時は .part が残り得る（次回書き出し時に1時間以上前のものを自動削除。data/work は起動時に掃除）。
- 音声コンテナの一部（wma 等）はブラウザで直接再生できないため、その場合は書き出しのみ利用可。
- .wmv など ASF の映像は互換表で ASF 出力の対象外としているため、常に MKV として書き出します（映像・音声はパケットコピー）。
- 出力コンテナを明示指定した場合、格納できない組み合わせは自動フォールバックせず 400 エラーになります。
- モバイル実機での最終確認は未実施（LAN URL は起動時に表示）。

## マイナスずらしの根本修正とデバッグログ（第57ラウンド）

### 症状
「ずらして書き出したファイルを再生してもズレない」＝ 書き出しにずらしが反映されない。

### 原因（2つ）
1. マイナスずらしを「映像側を |Δ| 遅らせる」で実装していた。映像は基準トラックなので、
   プレイヤーが映像の開始を 0 に正規化するとずれが消える（＝同期して見える）。
2. その過程で導入した「音声の内容を進める」方式が、計画の空判定
   （video/audio/added がすべて 0 なら計画なし）に引っかかり、audioSkipUs を見ていなかったため
   計画ごと破棄されていた。

### 修正
- マイナスずらしは音声の内容を |Δ| 進める方式に変更（切り出し区間を |Δ| 後ろへ）。
  両トラックとも 0 起点のままで、ずらしは内容に乗る。パケットコピーのまま（無変換）。
- 空判定に audioSkipUs を追加。
- 素材の終端に達する場合は終端でクランプし、警告を出す。
